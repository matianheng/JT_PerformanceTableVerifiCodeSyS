# JT_PerformanceTableVerifiCodeSyS

JTC100G6-性能表20260125-完整版-力限填充 根据性能表修改 CoDeSys

## 这是什么

动态版性能表校验 + ST 代码生成工具（单页网页，离线可用）。

- **上传 Excel 就地解析**：把性能表 .xlsx 拖进页面，自动识别 5 节臂 / 6 节臂表、18 个工况块（PRG），按标题自动对应（跨距 8.4m=全伸 F、5.5m=半伸 H；配重取右表 14t/20.5t→21；后移 800mm=HY）。
- **实时校验**：幅度重复/缺失、标题与跨距不符、配重分量和、数值非 100 倍数、同臂长随幅度上升、空白空洞、文本格、右表与原表不一致、填充版系数偏离 1.33，全部当场列出。
- **生成 ST 代码**：选 PRG → 组别（Full/Half/Third）→ 臂长，一键复制该臂长的 `Full_Weight[i,j]:= …;` 代码行；或一键复制整个 PRG（含臂长点/幅度点/Full/Half，结尾 `RETURN;`），直接粘贴进 CoDeSys。
- **动态查表**：输臂长 + 幅度，双线性插值算额定载荷；再输实际吊重，算载荷率（≥90% 预警、>100% 超载）。

## 使用

直接双击打开 `index.html` 即可。**打开时是空的，什么结果都没有**——传了你的 Excel 才开始解析、校验、生成；也可以点“使用内置数据”载入 2026-11-23 版（早上给的那份表）。上传解析需要联网加载解析库（cdnjs SheetJS），离线时只能用内置数据。

也可以在仓库 Settings → Pages 里打开 GitHub Pages，在线使用。

## 工作流（2026-11-23 晚新增）

1. **上传记一遍**：上传 Excel 后，工具记下文件名、时间、解析结果（存在浏览器本地），下次打开页面自动恢复，不用重新传；点“恢复内置数据”可切回 2026-11-23 内置数据。
2. **错误圈图**：第 2 节的圈图按当前选中的 PRG 与组别画表，确认错误红圈、待确认黄圈、在线改过的值蓝点；可下载 PNG 发给别人核对。圈只画在有错误的格子上，干净的表 0 圈是正常的，图上会写“本表没有错误格”；圈图下面有“有圈的表”跳转栏，点一下直接跳到有圈的表（全表 36×3 个组里只有 7 张表有圈）。
3. **改完再上传**：Excel 里改完错误重新上传，工具会报“上次 X 处错误 → 本次 Y 处，已修复 Z 处”；也可以不改 Excel，直接在第 3 节对照表的“Excel 值”格子里改，改完 ST 代码、校验、圈图同步更新（改原表会重算该列校验；“撤销全部在线修改”可恢复）。
4. **生成代码**：整 PRG 一键复制在上面；下面“分段复制”每个臂长各一个按钮，点哪个臂长就复制哪一段（含 `(*13.0m*)` 标题行）。

程序里 36 个表（五臂 JTC100 × 18、六臂 JTC101 × 18）与 Excel 原表共 **241 格不同**：

- **六臂只差 9 格**：HC00 35m/3~6m 程序 23000、Excel 23100（7 格）；HC38HY 47.6m/14m 程序 18500、Excel 18600（1 格）；FC27 60.1m/52m 程序 800、Excel 原表 "2100\n800"（1 格，程序的 800 是对的）。
