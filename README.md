# 起重机性能表通用校验 + ST 代码生成

上传任意车型的性能表 Excel，页面就地解析、校验、生成 CoDeSys ST 代码。
工具打开时什么都不知道，传了你的 Excel 才开始算；换个车型的表，改一下程序配置就能用。

## 使用

直接双击打开 `index.html` 即可。**打开时是空的，什么结果都没有**——传了你的 Excel 才开始解析、校验、生成。
离线可用：解析库是本地的 `xlsx.full.min.js`（SheetJS 0.18.5，与页面放同一目录），不加载任何在线库。把 `index.html`、`app.js`、`xlsx.full.min.js` 三个文件拷到一台电脑上直接双击打开就能用，不用联网。

## 表结构要求

- 每张表里每块以含“幅度(m)”的行作表头，上一行是标题，下一行（有序号行时下两行）是臂长行，数据行到“倍率”行结束。
- 横向多个复本按 24 列步长排：第 1 个是原表，第 2 个是右表（配重以右表标题为准），第 3 个是填充版。
- 同一块里的臂长按递减处自动分段：第 1 组进全伸数组，第 2 组进快伸数组；第 3 组及以后程序里没有对应数组，不出代码（在当前表信息里注明）。

## PRG 对应（按标题自动识别）

- 跨距：全文件最大的跨距 = 全伸（F），最小的 = 半伸（H）。标题里“全伸/半伸”文字不可靠，以跨距数字为准；文字与跨距矛盾会报确认错误。
- 配重：取右表标题里的吨数，数字按四舍五入取整、补到两位（20.5t 记作 21，0t 记作 00）。
- 后移：后移 0mm 无后缀，后移 >0 加后缀（默认 `HY`，可在配置里改）。
- PRG 全名 = 每张表的前缀 + 工况名（如 `JTC100` + `FC14`）。前缀在第 3 节的配置里按表填写，不填就只有工况名。

## 程序配置（第 3 节顶部，存在浏览器本地）

| 配置 | 默认 | 说明 |
|---|---|---|
| 全伸组数组名 | `Full_Weight` | 第 1 组臂长写进的数组 |
| 快伸组数组名 | `Half_Weight` | 第 2 组臂长写进的数组（第 0 行固定为全伸组第一个臂长，与全伸组同值） |
| 臂长点数组名 | `Arm_Length_Weight_Point` | |
| 幅度点数组名 | `Scope_Weight_Point` | |
| 写入条件 | `NOT TeleOut_Fast_Control_LMI` | 写在 `IF … THEN` 后面；清空则按 `TRUE` |
| 后移后缀 | `HY` | 后移 >0 的工况名后缀 |
| 幅度点上限 IEweightCol | `30` | 幅度点不足上限+1 个时按末尾步长顺延补齐（补 0）；超出上限的幅度列会在表信息里提示程序用不上；0 = 不限 |
| PRG 前缀 | （空） | 每张表一个 |

配置不跟着 Excel 文件走，换电脑/换浏览器要重新填。

## 校验规则（通用）

- 同一臂长随幅度增大不得上升（违反递减规律）。
- 孤立低点：某格比它上下两格都低，疑似孤立错数（错数常是孤立一格，邻格是好的锚点）；低于 1000 是待确认，超过 1000 是确认错误。低点本身报，下一格因此出现的“上升”不再重复报；若下一格是尖峰（升、降都超过本列正常步长的 3 倍，正常步长取本列递减值的 75 分位、下限 1000），则不报低点，只报尖峰。
- 首行（最小幅度）：同幅度下臂长越长载荷应越小，高出 2 倍以上是确认错误，略高是待确认；首行值超过次行值 2 倍是确认错误（疑似多打了 0）。
- 数值应为 100 的倍数（否则待确认）。
- 幅度不得重复/缺失；恰好一处重复 + 一处缺失且缺失值是重复值在主序列里的前一项时，自动把第一行重复值当作缺失值处理并提示。
- 标题配重分量和应等于吨数；左右表标题配重不一致要提示。
- 右表有值格须与原表一致；右表臂长网格与左表不同要提示。
- 填充版与原表的比值全文件应一致（偏离主要比值的块会提示）。

## 程序对比（主校验：第 1 节上传程序文件）

第 1 节第二个框上传 CoDeSys 导出的程序文件（`.export` 或 PLCopenXML `.xml`），工具逐格对比 Excel 里的值与程序里写的值，**差异是主校验，趋势是参考**：

- 对齐方式：按（臂长，幅度）数值对齐——程序用自己的 `Arm_Length_Weight_Point` / `Scope_Weight_Point` 数组找行列号，Excel 用表里的值（含 2.5m 这样的附加幅度列）。程序的 2.5m 列与 Excel 的 2.5m 列对上，不会错位。
- 差异标红：校验列表里红行（“程序 X，Excel Y，请核对纸质表”），圈图里红圈；分表差异数显示在第 1 节的程序信息里。
- 文本格、空白格也参与对比（文本格报“Excel 为文本…，程序为…”，空白格报程序值）；同一格的趋势问题（文本/空洞）不再重复报。
- 程序 POU 与 Excel 块的对应：精确匹配（配置前缀 + 工况键）优先；前缀没填时按工况键后缀匹配，臂长表最贴合的胜出（五臂/六臂同名工况靠臂长区分）。程序有、Excel 没有的表和 Excel 有、程序没有的表各报一次提示。
- 程序文件也记下来（解析结果存浏览器本地，下次打开自动恢复）；改配置（前缀/数组名）后对应关系重算；清除程序后回到只有趋势校验。
- 在线改格后，该格与程序的对比跟着重算；改成程序值，差异就消失。

## 工作流

1. 上传 Excel：记下来（文件名、时间、解析结果存浏览器本地，下次打开自动恢复）。
2. 上传程序文件（第 1 节第二个框）：与 Excel 逐格对比，差异标红；不传程序时只有趋势校验。
2. 错误圈图：第 2 节按当前选中的 PRG 与组别画表，确认错误红圈、待确认黄圈、在线改过的值蓝点，可下载 PNG。打开 / 重新上传时默认落到第一张错表（错得多的排前面），“上一张错表 / 下一张错表”只在错表之间翻。
3. 改完 Excel 再上传，工具报“上次 X 处错误 → 本次 Y 处，已修复 Z 处”。
4. 在线修改：第 3 节对照表“Excel 值”格子点开就能改，改完 ST 代码、校验、圈图同步更新；改原表重算该列校验，改填充版不重算校验；“撤销全部在线修改”可恢复。
5. 分段复制：每臂长各一个按钮，点哪个复制哪段（含 `(*13.0m*)` 标题行），整 PRG 一键复制仍在。

注意：在线修改只改页面里的数据，不改你的 .xlsx 文件；要改 Excel 本身请在 Excel 里改完重新上传。

## ST 代码格式

每个 PRG 生成：`(* PRG: 前缀+工况名 · 标题 *)` → 臂长点（`IF <写入条件> THEN … ELSE … END_IF`，全伸组臂长 / 快伸组臂长）→ 幅度点 → 全伸组各臂长 `数组[行,列] := 值;`（另加全 0 的第 9 行）→ 快伸组各臂长（第 0 行为全伸组第一个臂长）→ 其余行全 0 → `RETURN;`。
幅度点 = 主序列（不足上限时顺延补齐）+ 附加幅度行（如 2.5m 在最前面）；Excel 里没有的幅度填 0；文本格输出 0 并加注释。
